# GiftCash Landing Page

Responsive static landing page for GitHub Pages.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling
- `script.js` — mobile navigation and offer CTA setup

## Add your offer link
Open `script.js` and replace:
`const offerUrl = "";`
with your authorized offer URL inside quotes.

## Publish with GitHub Pages
1. Open your `giftcash` repository.
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, and `script.js` (or upload the ZIP contents after extracting).
4. Commit changes to the `main` branch.
5. Go to **Settings → Pages**.
6. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
7. Wait for GitHub Pages to publish the site.

The page uses Google Fonts from Google Fonts; if unavailable, it falls back to system fonts.
